# A.I.VOICE2 連携

## MacのVMSから使う

1. 音声パネル上部で「A.I.VOICE2」を選択します。「A.I.VOICE2を起動」の初回にアプリを指定できます。起動と直接合成は別で、抑揚・感情の直接操作は未接続です。
2. 製品側でセリフを**単一のWAV**に書き出します。VMSが合成エンジンを内蔵する機能ではありません。
3. 字幕欄にセリフを入力するか、WAVと同名のUTF-8 / Shift-JISの.txtを同じフォルダーに置きます。
4. キャラクターを選び、「WAVを選択して追加…」を押します。
5. 操作時の再生位置へ音声・字幕・立ち絵が追加されます。一度のUndoでまとめて取り消せます。

口パクは40msごとの音量解析による近似です。キャラクターの基本速度を反映し、無音では口を閉じます。音素の識別・文字単位の字幕同期は行いません。目パチは既存のキャラクター設定です。音声はプロジェクトのAssetsへ複製され、元ファイルを動かしても保存済みプロジェクトで利用できます。製品名は音声アイテムに保存し、VOICEVOXによる誤った再生成を無効にしています。

WAV上限: 30分、512MB。字幕.txt上限: 1MB。字幕なしの通常音声は従来の音声アイテム追加を使ってください。

## 監視フォルダー

「監視フォルダー…」でMacから見えるフォルダーを指定します。2秒間隔で直下のWAVのサイズと更新時刻を確認し、2回同じ値なら新規・更新ファイルとして一覧表示します。サブフォルダーは走査しません。監視開始前のファイルは一覧に出しません。

検出後も利用者が「追加」を押すまでタイムラインは変わりません。同名.txtの到着が遅れた場合やWAV書き込み途中だった場合は、完了後に再試行できます。製品切替、パネルを閉じる、アプリ終了で監視は停止します。監視先と取り込み待ち一覧はセッション限りです。

Windowsとのフォルダー同期・共有は利用者が設定してください。VMSはネットワーク共有やTailscale設定を自動変更しません。同期中のファイルを避けるにはWAVの転送完了後に追加してください。

## 旧方針の初代用Windows書き出し補助（対象外・実機未検証）

現在の対象はMac版A.I.VOICE2です。以下は旧方針の参考情報で、A.I.VOICE2のセットアップには使わないでください。

公式Editor APIを使う `Export-Voice.ps1` を同梱しました。**A.I.VOICE2用ではありません**。Windows PowerShell 5.1をログイン中の本人のデスクトップで使います。製品と公式DLLは別途必要で、VMSには含みません。

実行前に製品EULAと[API利用規約](https://aivoice.jp/manual/editor/api.html#termsandconditions)を確認してください。複数人向けサービスとして公開せず、自分の端末で使う補助ツールです。商用等の条件は提供元へ確認してください。

以下のパスはご自身のインストール先・保存先に置き換えてください。セリフファイルはUTF-8です。

```powershell
.\Export-Voice.ps1 -ApiDll "C:\インストール先\AI.Talk.Editor.Api.dll" -OutputDirectory "C:\VMS音声" -ListPresets -AcceptApiTerms
.\Export-Voice.ps1 -ApiDll "C:\インストール先\AI.Talk.Editor.Api.dll" -OutputDirectory "C:\VMS音声" -TextFile "C:\セリフ.txt" -VoicePreset "一覧で確認した名前" -AcceptApiTerms
```

Editorの音量・話速・保存設定を使います。分割保存はオフにしてください。合成中はEditorを操作しないでください。終了時は元の入力テキスト・選択・プリセット・入力モードを復元します。追加の生成メタデータや失敗時の出力は保存先の `.vms-voice_...` フォルダーに残します。

このMac環境ではWindows側の実合成は未検証です。VMSからの遠隔合成ボタン、認証付き遠隔操作、A.I.VOICE2のAPI合成、自動再生成は未実装です。
