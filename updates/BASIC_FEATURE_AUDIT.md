# 基本編集機能の点検（2026-09-07）

対象は現在のソース。一般的な編集機能の分類は Apple の動画編集ガイドも参考にしています。
https://help.apple.com/imovie/mac/

## 既存の接続を確認したもの

- 素材取り込み、複数レイヤー、選択・移動・長さ変更、コピー/貼り付け、削除/左詰め削除。
- 保存・読み込み、プロジェクト値のUndo/Redo、共通プレビュー/動画出力。
- 静的X/Y・拡大率・回転・左右反転・不透明度・フェード・合成モード。
- ぼかし、字幕の縁取り・影・グラデーション。

これは全項目の実機操作試験済みという意味ではありません。

## 今回追加・修正

- VisualEffectモデル：移動/拡大縮小（等速/なめらか）、振動、連続回転、拡縮反復、なめらかな点滅。
- 明るさ/コントラスト/彩度/色相、上下反転、画面範囲の切り抜き。
- 未対応だったモノクロ、白い光彩の発光、モザイクを描画へ接続。
- 映像効果の処理順、無効化、複製、削除。字幕装飾は映像スタックの前に適用。
- 分割/左端トリム後のアニメーション時刻を維持。
- 手前に表示/Z値順を実描画へ接続。通常項目は安定したレイヤー順を維持。
- 変形エフェクト使用中は位置ハンドルの誤操作を避けるため直接ドラッグを停止。共通X/Yで調整。
- 数値定義をモデルへ集約し範囲・非有限値を補正。効果は主選択対象、ロック中は変更不可。
- 多数の効果で無制限に中間描画を作らないよう映像効果は64件まで。

## 残る基本機能・制約

- クロマキー、任意形状マスク、自由な中間キーフレーム。
- 再生速度変更/逆再生、場面間トランジション、エフェクトプリセット保存。
- 音声は同一コンポジショントラックへ挿入する既存設計。重なった音声の独立ミックスは別途修正が必要。
- 音声のパン等は設定値があるだけの箇所があり、実処理への接続を別途点検する必要あり。
- 左端トリム/分割の音声・動画ソース開始位置の扱いは別途改善が必要。今回直したのは映像効果の時刻。
- 上の素材によるクリッピングは未接続。画面範囲の切り抜きとは異なる。
- 自然言語チャットから新エフェクトを追加するAIコマンドは未接続。
- 持ち運び用Macへの配布・起動・実動画の目視再生試験は未実施。
- 色調整/モザイクは透明な中間画像をCore Imageで処理するため高解像度・多数効果では負荷が増す。CIContextを共有し連続した色処理はまとめて実行。

## 検証方法

今回の結果：VMSCore 42件（41成功、実機音声1件スキップ）。実Canvas描画テストで、全非字幕装飾エフェクトの画素変化/無効化、各色調整、処理順、字幕・キャラクター・動画フィクスチャの移動を確認。モノクロ・発光・モザイクのPNGも目視確認。実際の動画ファイルのデコード/書き出し再生はこの描画テストの対象外。

- `Packages/VMSCore` で `swift test --scratch-path /tmp/vms-voice-tests`。
- `Tools/Tests/EffectsRenderSmoke.swift` は実際の `CompositeFrameView.swift` と `CodableColor+SwiftUI.swift`、VMSCoreのオブジェクトをリンクする描画検証用。ユーザー素材は使わず赤/青のテスト画像を生成。
- テスト画像出力先：`/tmp/vms-effects-render-smoke`。
- 最終的な操作確認：素材選択→共通→エフェクト一覧→追加→振動、振幅と速さを変更→再生→チェック解除→Undo/Redo→保存・再読込→動画出力。
