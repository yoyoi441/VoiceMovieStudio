# 音声プロバイダーの拡張予定

利用者が希望する対象は、Mac版 **A.I.VOICE2**（2026-09-07の追加指示で初代から変更）。
汎用のAI音声生成とは分けて対応を設計する。

## 製品別の接続方針

- 初代向けWindows API連携は現在の対応対象から外す。
- A.I.VOICE2: 公式製品ページは現時点で「API連携なし」と記載。AppleシリコンMac版もあるが、初代のAPI対応を引き継ぐと仮定しない。まず利用者が書き出した音声の取り込み・監視フォルダー連携を候補とし、合成操作の完全自動化とは区別する。
- A.I.VOICE2アプリを選択して起動する入口を追加。直接操作は実機のインストール先と操作可能なUIを確認してから設計する。内部APIや未確認の操作座標を推測して実装しない。製品・ライブラリは利用者が別途用意し、公開アプリへ同梱しない。

確認資料: [Editor API](https://aivoice.jp/manual/editor/api.html)、[A.I.VOICE2製品仕様](https://aivoice.jp/about/aivoice2/)、[初代の動作環境](https://aivoice.jp/manual/editor/en-us/system_requirements.html)

## VMS側の共通設計

- 既存の VoiceEngine / SynthesizedSpeech を接続境界とする。
- 本体PCまたは自宅の高性能PCで音声を生成し、携帯PCに音声とタイミング情報を返す。
- 音声・字幕・口パクの追加は既存の TTSImportService を利用する。
- 話者とスタイルの識別子、非対応の音声パラメーター、音素時刻を取得できないエンジンへの対応を設計する。
- 接続先・認証・接続テスト・音声試聴をキャラクター設定から選べるようにする。

実装済み: A.I.VOICE2のアプリ指定・起動入口、WAV取り込み、字幕・音量ベース口パクの一括追加、監視フォルダーの検出一覧、音声元の保存と誤再生成の防止。起動入口のA.I.VOICE2実機検証は未完了。
VOICEVOX: エンジン由来の話者別スタイル、抑揚・話速等の編集、試聴、キャラクター音声初期値保存、再生成時の連動更新を実装。実エンジンでスタイルと抑揚による音声変化をテスト済み。
A.I.VOICE2のVMS内からの直接合成・抑揚・感情操作は未実装。持ち運び用Macで /Applications/AIVoice2.app、バージョン2.14.1、bundle ID jp.ai-j.AIVoice2 を確認済み。公開スクリプト辞書は見つからない。次に実画面とアクセシビリティによる操作可否を検証する必要がある。
利用手順は [連携ガイド](../Tools/AIVoice/README.md) を参照。
