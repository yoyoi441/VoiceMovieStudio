# ボイスムービースタジオ 1.2.2

> [!WARNING]
> このソフトウェアは開発中のプレリリース版です。機能や保存形式が変更される可能性があり、動作も安定していません。重要なプロジェクトは必ずバックアップを作成し、出力結果を確認してから利用してください。

macOS向けの動画編集アプリです。動画・画像・音声・キャラクター素材をタイムラインへ配置し、字幕、音声生成、クレジット作成、このMacまたは別端末を利用したAI解析を行えます。

## 動作環境

- macOS 14以降
- Apple SiliconまたはIntel Mac（AIワーカーはApple Silicon推奨）
- 動画出力に必要な十分な空き容量
- 音声生成を使用する場合は対応する音声エンジン
- Mac音声を使用する場合は、macOSにインストールされた日本語システム音声
- AquesTalk Player連携を使用する場合は、利用者が公式サイトから導入したMac版AquesTalk Player

## インストール

1. 配布ディスクイメージを開きます。
2. `VoiceMovieStudio.app`を`Applications`へドラッグします。
3. アプリを起動し、初回チュートリアルを確認します。

公証前のテスト配布版ではmacOSが開発元を確認できない場合があります。正式配布版はDeveloper ID署名とApple公証後に公開してください。

## 基本操作

- Finderから素材を編集画面へドラッグして追加
- タイムライン中央のドラッグで移動、左右端で長さ変更
- 空き部分をクリックして再生位置を移動
- `Command+S`でプロジェクト保存
- 「動画出力」で完成動画を書き出し
- 「クレジット」で概要欄用テキストを作成
- 「AI」でこのMacまたはリモートMacのAIノードへ接続
- 絵コンテの「台本からコマを追加…」でTXT・CSV・JSONのシナリオを読み込み、必要に応じてAIへ話者・表示時間・左右配置の提案を依頼
- 絵コンテの「AI情報を書き出す…」でAI編集用JSONを作り、AIが編集したJSONを検証・差分確認してからタイムラインへ仮組み

詳しい説明はアプリ内の「ヘルプセンター」を参照してください。

## Macローカル音声

音声パネルとキャラクタープリセットで「Mac音声」を選ぶと、別PCや接続設定なしでmacOSの日本語システム音声を使用できます。「霊夢向け」「魔理沙向け」は声・高さ・話速の初期候補で、Mac内のKyokoとReedを優先します。特定の市販音源と同じ声ではないため、試聴してキャラクターごとに調整してください。

## AquesTalk Player連携

利用者が公式サイトから導入したMac版AquesTalk Playerを検出し、公式のコマンド実行機能でWAVを生成できます。プリセット名はキャラクターごとに保存され、音声・字幕・音量ベースの口パクへ反映されます。AquesTalk Player本体や音声ライブラリは本アプリへ同梱・再配布しません。

AquesTalk Playerは個人かつ非営利の場合に限り無償です。収益化、業務、個人事業、法人・団体・教育機関での利用にはAQUESTの使用ライセンスが必要です。秘密のライセンスキーはAquesTalk Player側だけで設定し、本アプリ、プロジェクト、Gitへ保存しないでください。最新条件は[AQUEST公式ページ](https://www.a-quest.com/products/aquestalkplayer.html)で確認してください。

## ローカル／リモートAI

同梱の`AIWorker`は、編集しているMac自身、または別のApple Silicon Macを文字起こし・重要箇所抽出・クリップ作成用ノードにします。AI画面の「このMac」と「リモートMac」は別々の接続プロファイルで、URL・モデル・接続トークンを切り替えて使えます。導入手順は[AIWorker/README.md](Tools/AIWorker/README.md)を参照してください。

## データについて

- プロジェクトと取り込んだ素材は`.VMS`パッケージへ保存されます。
- 接続トークンとAPIキーはmacOSキーチェーンへ保存されます。
- AI処理へ渡す内容は実行場所によって異なります。詳しくは[PRIVACY.md](PRIVACY.md)を参照してください。

## 配布する開発者向け

- 公開前に`Scripts/check_distribution_privacy.sh`を実行してください。Release作成とGitHubの更新時にも自動実行されます。
- 個人用の接続先、トークン、署名チームID、絶対パス、プロジェクト、キャラクター素材はGitへ追加しないでください。
- GitHub Actionsで作る配布版は、更新フィードURLを実行中の公開リポジトリから生成します。アカウント名をソースへ固定しません。
- 開発版Releaseも検出できるよう、署名済みappcastを`main`の`updates/appcast.xml`へ反映します。Releaseのタグを削除したり下書きへ戻すと更新できません。
- ローカルで配布版を作る場合は、公開する更新フィードを`UPDATE_FEED_URL`環境変数へ指定してください。未指定のビルドでは更新確認先に無効なサンプルURLを使います。
